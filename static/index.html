About this Project

Architecture, Machine Learning methodology, and dataset specifications

🎯

Project Objective

The objective of Customer Churn Analysis and Prediction is to build, evaluate, and deploy supervised machine learning models to accurately detect customer churn before it occurs. Early detection enables subscription providers to optimize customer lifetime value (CLV) and stabilize recurring annual revenues.

🤖

Algorithms Used

  • Random Forest Classifier: Active production model utilizing 100 bootstrapped decision trees to deliver balanced, low-variance probability predictions.
  • Logistic Regression: Linear probabilistic baseline model calibrated using the Sigmoid activation function.
  • Decision Tree Classifier: Rule-based hierarchical classification constrained to depth 4 to prevent overfitting.
📊

Dataset Details

  • Name: Telco Customer Churn (IBM Cognos Analytics)
  • Records: 7,043 customer accounts
  • Features: 20 attributes spanning demographics, account services, and billing
  • Class Distribution: 5,174 Retained (73.46%) vs 1,869 Churned (26.54%)
⚙️

Machine Learning Approach

  • Data Cleaning: Converted TotalCharges from string to float, handled 11 missing zero-tenure values, removed non-predictive customerID.
  • Encoding: One-Hot Encoding via dummy variables (`drop_first=True`) creating 30 mathematical input features.
  • Evaluation: Stratified 80/20 train-test split, Confusion Matrix, Classification Report, and ROC-AUC curves.
  • Persistence: Serialized with `joblib` into `models/` for sub-millisecond inference in FastAPI.
